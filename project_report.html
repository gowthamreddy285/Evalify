Evalify

Technical Architecture & Development Report

1. Project Mission

Evalify is a state-of-the-art AI-powered platform designed to disrupt traditional technical interviewing. By combining high-speed LLM inference with deep NLP analysis, it provides candidates with a high-fidelity simulation of elite-tier company interviews.

2. Core Technology Stack

Backend Infrastructure

  • FastAPI: High-performance Python framework for building asynchronous APIs.
  • MongoDB & Beanie OGM: Scalable NoSQL database with asynchronous object mapping.
  • Groq (Llama 3.3 70B): Lightning-fast LLM inference for question generation and judging.
  • Sentence-Transformers: Local embedding model for semantic similarity analysis.
  • spaCy & LanguageTool: NLP suite for communication and grammar evaluation.

Frontend Interface

  • React & Vite: Modern, reactive UI framework with fast builds.
  • Framer Motion: Advanced animation engine for a premium, interactive feel.
  • Tailwind CSS: Utility-first CSS for handcrafted design tokens.

3. Intelligence Engine

Feature

Personalized Questioning

Implemented a dynamic prompt engine that synthesizes the candidate's Resume and the Job Description to generate unique questions. Every question is tailored to the candidate's specific projects and tech stack.

Feature

3-Layer Evaluation Logic

We developed a weighted scoring system that combines:

  • AI Judge Score (50%): Contextual technical correctness.
  • Semantic Similarity (30%): Meaning-based matching.
  • Keyword Coverage (20%): Technical terminology detection.
Feature

Delivery Analysis

Integrated Whisper transcription to analyze verbal communication, including filler word detection, pace, and clarity scoring.

4. Security & Optimization

We implemented several enterprise-grade security and performance patches:

  • Async Multi-threading: Wrapped blocking AI and NLP calls in asyncio.to_thread to ensure the API remains responsive under load.
  • Google OAuth 2.0: Secure, password-less authentication using Google's trusted identity provider.
  • Rate Limiting: Integrated slowapi to prevent API abuse and control operational costs.
  • JWT Session Management: Secure token-based authentication with properly managed environment secrets.
  • CORS Restriction: Locked down the API to only trust authorized origins.

5. Why We Chose This Path

The goal was to build a Production-Ready platform, not just a prototype. By choosing MongoDB, we ensured scalability. By choosing Groq, we ensured real-time responsiveness. By implementing async wrappers and rate limits, we ensured the system could handle multiple users safely and cost-effectively.
